# 2.1 BUCK理论基础

1. 电感的激励是电压。电容的激励是电流。稳态储能元件周期初始值=终值。因此，激励的周期净值应该为0。

   电感伏秒平衡、电容安秒平衡

   $i_L(T_s) - i_L(0) = \frac{1}{L} \int_0^{T_s} v_L(t) dt$

   $0= \int_0^{T_s} v_L(t) dt$

   $v_C(T_s) - v_C(0) = \frac{1}{C} \int_0^{T_s} i_C(t) dt$

   $0= \int_0^{T_s} i_c(t) dt$

​	水龙头是激励，是变化率。水桶（电感电流、电容电压）是对应的值。电感大，相当于水桶大，相同的激励下，变化斜率越小：uL=Ldi/dt.

2. 电力电子电路的稳态指周期性重复的稳定运行状态而不是绝对不变的稳态。

3. **DCDC稳态分析方法：**

   1. 根据电路中【开关的象限与控制方法】，做出不同的电路模态，标出电感电容的电流电压参考方向

      > 注意：**DCDC电路的本质内核应该是不同的电路模态**，开关器件与其对应匹配的控制方法设计并不唯一，能实现模态切换就行！
      >
      > **buck与boost不是一拍脑袋就出来的拓扑，而是计算出来的，有设计方法的，由仿真验证**
      >
      > 搞明白要设计的电路不同的状态（包含不同路的通与断）->对应支路根据模态分析这些开关的运行象限->确定开关（单个或者多开关器件复合而成）
      > 多象限向低象限兼容

   2. 找出电路中不同模态电感电容的激励表达式

   3. 【第一次小纹波近似】使用iL与uC的平均值来代替**（现实是不合适的，因为拓扑变换，根据电路理论，会有充放电的过程）**

      > 先小纹波，才能出积分里面提出来，成为常数×时间

   4. 伏秒平衡、安秒平衡，得到两个平衡方程：< vL >=...=0、< ic >=...=0

   5. 分析求解（1）M(D)（2）直流分量

   6. 带入2的激励表达式，【第二次小纹波近似】，得到激励大小

   7. 画出储能元件上激励波形→电感电流与电容电压波形→做出开关器件波形**（根据此步可以进一步计算纹波，辅助器件选型）**

   **局限性：这种稳态分析方法分析出来结果（波形，电感电容计算公式）比较粗略，二阶滤波器等结构还需要进一步分析。**

4. 同步buck与普通buck有什么区别

   普通BUCK：

   使用**二极管**（D1）作为续流元件。当主MOS管Q1关断时，电感电流通过二极管D1续流。

   **缺点**：二极管导通时具有较大的管压降，会造成较大的导通损耗。

   同步BUCK：

   > 同步 = 与主MOS管的开关动作"同步配合"

   使用**MOS管**（Q2）代替续流二极管，并控制Q2的导通模式与原来续流二极管的导通模式相同（即Q1开通时Q2关断，Q1关断时Q2开通，两者互补工作）。

   **优点**：**MOS的导通内阻较低，相比二极管能显著降低导通损耗，提高变换器效率。**

1. 明确主控器件，因为占空比是针对主控器件的占空比进行描述的

2. ![image-20260201210513676](./Sync buckbost notes_images/img_007.png)
   - 输入都是最低12V：小于12V欠压保护，不开启工作
   - buck输出电压范围：0-50V，0对应D为0，50V对应，输入50，D取1。

   - 最高电压电压是由电路整体的耐压上限决定的 

3. 额定值指经常运行的状态的值，被人为定义的

4. 以buck为例，输出电流的波形是电感与电容的共同作用结果：电感越大，对应电感电流的纹波斜率就越小，越平滑，电容就可以取的低一点。如果电感小，电容就要取大一点。因此硬件计算没有一个很固定的计算方法

5. 可以在仿真中看出，器件大小影响输出电压的质量（纹波大小），但是都是可以正常工作的。纹波越小，要求电感电容都越大，经济性变差，因此要往往考虑到经济效益+输出质量的折中。

8. 关于电感与变压器的一些特性：

   1. 电感感值越大，一般对应的内阻就越大，损耗就越大；
   2. 电感的公式：$L=\frac {μAn^2}{l}$，一般电感和变压器为了增加电感值都有磁芯（μ增大）。由于磁滞回线，当电流增大，H增大，B随H呈μ的斜率增大。但到一定值时，H增大，μ会变小，并且变小的很快，此时L就会剧烈的变小，相同电压激励的情况下，电感电流变化率很变的很大（相当于水流不变，水桶变小），产生很高的电流峰值，使得开关器件等元件被击穿。**（电流值增大对电感的衰减作用）**

### 4.1.2 驱动电路

- 为什么stm32产生的PWM波不能直接连接到栅极？

  MOS管的开通本质上是一个**对栅极电容充电**的过程。栅极等效为一个电容（Cgs + Cgd），驱动电路需要向这个电容灌入电荷，把Vgs从0V充到足够高（比如10-12V），MOS才能完全导通。stm32的驱动能力很差（提供灌电流的能力只有10mA，属于信号级别，不是功率级别）， 要为A级别才能保证mos管的开通速度。

- 驱动对mos管导通关断本质上是对Cgs充电放电的过程，充放电越快，导通关断越快

- 驱动电路的核心作用是**在控制信号（单片机PWM，3.3V弱电）和功率MOS（需要大电流驱动）之间做桥梁**，具体体现在：

  **1. 电平转换** 单片机输出的PWM是3.3V逻辑电平，而MOS的栅极需要12V才能完全导通（降低导通内阻），驱动芯片SI8233BD负责把3.3V信号转成12V驱动信号。

  **2. 提供瞬间大电流（快通快关，你说的这点）** MOS的栅极等效为一个电容，要让它快速充放电就需要瞬间大电流。单片机IO口电流能力很弱（几毫安），根本带不动。SI8233BD有4A的驱动电流能力，能快速给栅极电容充放电，从而实现快速开通和关断，降低开关损耗。

  **3. 隔离（这个项目特有的重点）** SI8233BD是隔离型驱动芯片，耐压4000V，将功率级和控制级电气隔离开来，防止功率电路的高压高频噪声直接冲击单片机，保护控制电路。

  **4. 死区控制，防止直通** 上管Q1和下管Q2绝对不能同时导通，否则电源直接短路。SI8233BD的DT引脚可以设置死区时间，保证两路驱动信号之间有足够的间隔，这是安全性保障。

  所以驱动电路 = 电平转换 + 增强驱动能力（快通快关）+ 隔离保护 + 死区防直通

### 4.1.3 调理电路

- 采样的信号：

  - 输出电压电流控制：buck：Y端电流电压；boost：X端电流电压
  - 电感电流控制：电感电流
  - 两颗mos管的温度：散热器温度
  - 电压旋钮电流旋钮输出采集

- 准确的将采样的物理量准确的转化为0-3.3V可供ADC转换的电压值，同时软件进行真实物理值的还原

- **调理电路的核心作用有以下几点：**

  **1. 幅值缩放（缩放到0-3.3V内）**:电路中的X端/Y端电压最高可达48V，而单片机ADC的量程只有0~3.3V，所以用差分放大电路将其按比例缩小。例如X端电压调理的放大倍数约为0.049倍，24V输入对应输出约1.615V，落在ADC可采样范围内。软件再反推回实际电压值。

  **2. 处理负值信号（双向测量的关键）** 这个项目是BUCK/BOOST双向变换器，电流会有正向和反向，但ADC只能采0~3.3V，无法直接识别负电压。解决方法是在差分放大电路的正输入端叠加一个1.65V的偏置电压，让"零电流"对应输出1.65V，正向电流对应高于1.65V，反向电流对应低于1.65V，软件再减去偏置量换算出真实电流。

  **3. 差分采样（抗共模干扰）** 大电流流过地平面时，各点地电位并不完全相同，会引入误差。使用运放构成的差分放大电路，只采集两点之间的差值，消除地平面噪声对测量的影响。

  **4. 低通滤波（去除开关噪声）** 功率变换器开关频率高，会产生大量高频噪声叠加在信号上。调理电路的输出端加了1KΩ+1nF的RC低通滤波，ADC端口还有100Ω+330pF的二级滤波，防止高频干扰影响采样精度。

  **总结：** 调理电路 = 幅值缩放 + 偏置处理（支持双极性） + 差分抗干扰 + 低通滤波，最终目的就是把各种真实物理量（电压、电流、温度）转换成单片机ADC可以准确读取的0~3.3V信号，软件再根据对应的比例系数还原成实际值。

### 4.1.4 辅助电源

这个项目中主电路输入是24~48V的大电压，但控制器、驱动芯片、调理电路各自需要不同的低压供电，不能直接用主电路电压，所以需要辅助电源把主电路电压转换成各路所需电压。

**A3V3  是模拟电源，D3V3是数字电源**  

**本质区别：噪声特性不同**

**D3V3（数字电源）** 数字电路（单片机内核、GPIO、定时器等）工作时，信号在0和1之间高速切换，每次切换都会产生瞬间的大电流冲击，导致**电源上叠加大量高频噪声**。数字电路本身对这些噪声不敏感，因为它只关心信号是高还是低，有一定容忍范围。（数字电源混杂高频信号）

**A3V3（模拟电源）** ADC采样电路对电源噪声极其敏感。ADC在测量时，参考电压稍有波动，采样结果就会出现误差。比如STM32的12位ADC，量程3.3V，最小分辨率约为0.8mV，电源上哪怕几毫伏的噪声都会直接影响采样精度。（模拟电源更加干净）

**这个项目怎么处理的**

数字电源D3V3先产生，然后经过CLC滤波电路（CB11电容 + LB1电感 + CB9电容）进一步滤除高频噪声，生成更干净的A3V3专门给ADC的模拟供电引脚使用。

```
D3V3 → [C + L + C 滤波] → A3V3（更干净）
```

电感L对高频噪声呈高阻抗，能有效阻止数字电路的噪声窜入模拟电源，两侧电容则把噪声旁路到地。

**一句话总结：** 本质是同一个电压3.3V，**但A3V3经过额外滤波更干净，专门给ADC用，防止数字电路的开关噪声污染采样结果**，保证测量精度。

## 4.2 控制板

接受采样信号，输出pwm控制信号

**输入侧（接收信息）**

- 接收各路调理电路送来的ADC采样信号：X端电压、X端电流、Y端电压、Y端电流、电感电流、温度
- 接收用户指令：旋钮设定的目标电压和目标电流

**处理（控制板的核心价值）**

- 单片机内部运行控制算法（比如PID），将采样到的实际值与目标值进行比较，计算出误差
- 根据误差实时调整PWM的占空比，从而控制输出电压和电流趋近目标值
- 这个"采样→计算→调整"的闭环过程每个开关周期都在高速运行

**输出侧（发出控制）**

- 输出PWM信号给驱动电路，驱动电路再去控制MOS的通断

**其他职责**

- 通过串口与上位机通信，接收远程指令、上报运行状态
- 驱动LCD显示屏显示电压电流等信息
- 监测温度，过温保护
- 响应按键操作

**一句话总结：** 控制板就是整个电源的"大脑"，采样和PWM输出是它的手脚，控制算法才是它真正的价值所在，没有闭环控制，输出电压就无法稳定。

1. 浮点数运算时间长，200kHz的PWM对应的周期为5ms，要在5ms内完成诸多计算，但是浮点运算占用的主屏周期多，因此要少用浮点运算。

2. 工程上通常的替代做法是**数字化定标**（也称为“定标”或“标定”）：是指将实际的物理量（如占空比、电压、电流）转换为控制器（如 STM32）能够高效处理的整形数字量（整数）的过程。这样全程用整数运算，速度快、精度可控、结果可预期。

   例如：占空比1对应$2^{15}$，0.5对应$2^{14}$

   stm32的ADC时，采样寄存器就相当于数字化定标，本项目使用Q12格式进行定标（12位寄存器），对应3.3V即为$2^{12}$，使用虽然严格来说 3.3V 时 ADC 输出的最大值是 4095（$2^{12}-1$），但用 4096（$2^{12}$） 作为分母误差极小（约0.02%），且显著提升了运算效率（因为除以2^12，可以直接>>12右移12位，速度很快）。

3. **电流采样定标全过程**：以Y端输出电流定标为例

   **一、硬件信号调理（模拟域）**

   实际电流经过 $0.001\Omega$ 取样电阻和增益100的差分放大电路，转换为ADC可采样的电压：

   $$U_{adc} = i \times R_y \times Gain + 1.65V = 0.1i + 1.65$$

   引入1.65V偏置的目的是使电路能同时表达正向和反向电流：

   | 实际电流 | ADC输入电压 |
   | -------- | ----------- |
   | +16.5A   | 3.3V        |
   | 0A       | 1.65V       |
   | -16.5A   | 0V          |

   ------

   **二、ADC采样（模拟→数字）**

   STM32 ADC配置为12位采样，参考电压3.3V，采样范围0~4095：

   $$\text{ADC数字量} = \frac{U_{adc}}{3.3V} \times 4096$$

   | 实际电流 | ADC输入电压 | ADC数字量 |
   | -------- | ----------- | --------- |
   | +16.5A   | 3.3V        | 4096      |
   | 0A       | 1.65V       | 2048      |
   | -16.5A   | 0V          | 0         |

   此时ADC数字量与实际电流

   ①**不成比例关系**（0.1i + 1.65为线性关系，非比例关系，存在2048的偏置）。

   ②保证相同电流大小对应的定标值相同

   ------

   **三、软件定标处理（数字域）**

   // BUCK模式（正向电流0-16.5A）
   实际电流定标值 = ADC采样值 - 2048

   | 实际电流 | ADC数字量 | 定标值 |
   | -------- | --------- | ------ |
   | +16.5A   | 4096      | 2048   |
   | 0A       | 2048      | 0      |

   // BOOST模式（反向电流-16.5~0A）
   实际电流定标值 = 2048 - ADC采样值

   | 实际电流 | ADC数字量 | 定标值 |
   | -------- | --------- | ------ |
   | -16.5A   | 0         | 2048   |
   | 0A       | 2048      | 0      |

   两种模式都保证最终处理的定标值为正数，方便后续环路计算。

​	对应最终都是0→0、16.5→2048

> 补充差分放大器放大倍数运算：
>
> **电路结构分析**
>
> 根据图中元件：
>
> - R14 接在 VX+ 和同相端(+)之间
> - R19 接在 VX- 和反相端(-)之间
> - R11 接在反相端(-) 和输出之间（反馈电阻）
> - R22 接在同相端(+) 和 GND 之间
>
> 四个电阻构成标准差分放大器结构。
>
> ------
>
> **用虚短虚断推导**
>
> 设同相端电压为 V+，反相端电压为 V-，输出为 Vout。
>
> **第一步：求 V+（对同相端用分压）**
>
> 由虚断，同相端无电流流入，R14 和 R22 对 VX+ 分压：
>
> $$V_+ = VX_+ \cdot \frac{R22}{R14 + R22}$$
>
> **第二步：对反相端列 KCL**
>
> 由虚断，流过 R19 的电流等于流过 R11 的电流：
>
> $$\frac{VX_- - V_-}{R19} = \frac{V_- - V_{out}}{R11}$$
>
> **第三步：由虚短 V- = V+**
>
> 代入 V- = V+，整理得：
>
> $$V_{out} = V_+ \cdot \left(1 + \frac{R11}{R19}\right) - VX_- \cdot \frac{R11}{R19}$$
>
> 将 V+ 展开：
>
> $$V_{out} = VX_+ \cdot \frac{R22}{R14+R22} \cdot \left(1+\frac{R11}{R19}\right) - VX_- \cdot \frac{R11}{R19}$$
>
> ------
>
> **当四个电阻满足对称条件 R14=R19，R11=R22 时**
>
> 公式化简为经典差分公式：
>
> $$V_{out} = \frac{R11}{R14} \cdot (VX_+ - VX_-)$$
>
> 这时放大倍数才是 **R11/R14**。
>
> ------
>
> 图中 R14=R19=68KΩ，R11=R22=3.3KΩ，**四个电阻满足对称条件**，所以最终结果确实是 R11/R14，
>
> 但推导过程必须走完整的差分放大器推导，不能直接套反相放大器公式 R11/R14，两者虽然数值结果相同，但物理含义完全不同。
>
> 放大倍数 = 3.3K / 68K ≈ **0.049**，这与项目文档中描述的 X 端电压调理放大倍数完全吻合

## 5.2 PID控制

- 开环仿真：**直接告诉控制信号的占空比。**通过公式（如Buck: D = Vo/Vi）直接算出占空比 → 送入变换器 → 输出稳态电压没有反馈，算对了就对了，但**扰动来了没人管**

- 闭环控制：**使用负反馈，我不直接给你占空比了，而是给控制量的给定值，控制器利用误差来自己调整占空比是多少**，如图

  ![image-20260317104145883](C:\Users\23227\AppData\Roaming\Typora\typora-user-images\image-20260317104145883.png)

  Vos目标（给定电压）和实际输出Vos在比较器（圆圈⊗）处做差，得到误差信号 e(t) = Vos目标 - Vos。误差送入控制器（比如PI或PID），控制器将误差转换为占空比 DutyS。占空比送入Buck变换器，Buck根据占空比工作，输出电压Vos。

  Vos小于Vos目标，e(t)越大，对应PID输出的DutyS就越大，对应Vos就越大，对应e(t)越小，来回几下逼着系统向稳定方向走（e(t)为0）。

  **好处：电源大小变化、负载在小范围变化时，反应到Vos上，产生误差，占空比自己跟着变化，输出跟随指定，不用管给多少占空比**
  
  ![image-20260301195157621](C:\Users\23227\AppData\Roaming\Typora\typora-user-images\image-20260301195157621.png)
  
  此图：48Vin 24V给定，PI调节

> ①**不管是什么控制器，负反馈的逻辑方向很重要**——你得确保**"误差通过控制器产生的调节动作，其效果是减小误差本身"**，这才能倒逼系统收敛到给定值。P、I、D三个环节各自用不同方式处理误差，但都必须满足这个方向性要求。
>
> 例子：Vo偏小 → e偏大 → D增大 → Vo被拉回来。这个链条里每一步的"增减方向"都不能反，反了就变成正反馈，系统会跑飞。
>
> ②所有负反馈控制器的本质都是**"误差大控制器输出大”**，这个方向永远正确。
>
> ②注意DutyS及所有量都是时时刻刻变化的，但是作用在buck上只能是每个控制周期也就是每个PWM周期作用。

| 控制器              | 本质行为                                                     | 补充说明              |
| ------------------- | ------------------------------------------------------------ | --------------------- |
| P（比例）           | 误差大→输出大，<br />误差小→输出小<br />误差零→输出零        | 最纯粹，但有稳态误差  |
| PI（比例积分）      | 误差大→输出持续增大，增长快<br />误差小→输出持续增大，增长慢<br />误差零→输出维持不变 | I的作用是消除稳态误差 |
| PID（比例积分微分） | 误差变化快→额外增大输出                                      | D的作用是提前预判趋势 |

### 1. P

$$Duty = K_P \times e$$

输出达到目标值，对应e为0，但 $Duty = 0$，Buck没有输出。所以必须有 $e \neq 0$，即存在静差，输出**永远达不到**目标值。

------

### 2. I

$$Duty = K_I \times \int e(t)dt$$

输出达到目标值， $$e = 0$$

可以达到稳定电压

- 如果KI设计的太小：误差始终大于0，一开始误差大，输出上升快，之后误差越来越小，上升越来越慢，使得达到稳态时间变长

- 如果KI设计的太大：误差在大于小于0之间振荡，在Vo之间振荡

**所以实际使用PI组合：**

- **P负责**：快速响应误差，让输出迅速接近目标
- **I负责**：慢慢消除剩余静差，最终精确到达24V

### 3.D

- 在此项目中，当Kd为正，如果de(t)/dt为正，那就是误差有变大的趋势（愈加偏离给定值），D输出与PI同向叠加，加大调节力度，使得输出占空比标定值愈大。如果de(t)/dt为负，那就是误差有变小的趋势（愈加靠近给定值） ，D输出与PI反向，相当于提前"踩刹车"，避免系统超调。
- 常用在一些**惯性比较大的控制领域**，比如温度控制，避免超调，D的"预刹车"作用很有价值。电源控制中开关频率高、响应快，D对高频噪声敏感（因为噪声的de/dt很大），容易放大噪声引发振荡，所以实际电源设计中PI用得多，D很少用。

### 一、 控制系统与扰动来源

在实际开关电源中，主电路会受到各种扰动，这些扰动最终都会反映到输出电压上。我们可以将它们等效为输出端的综合扰动信号 $V_{dist}$，如图（a）与图（b）所示。主要扰动来源包括：

- **扰动来源1：负载突变**（如负载电流瞬间从 1A 跳变到 5A，导致输出电压瞬间跌落）。
- **扰动来源2：输入电压波动**（如输入端电压从 24V 波动到 23V，传递到输出端引起波动）。
- **扰动来源3：开关纹波**（MOS管以特定的频率开关，输出不可避免地叠加开关频率纹波）。

### 二、 频域分解与叠加定理

由于系统已经过小信号线性化处理，我们可以利用傅里叶变换[^1]，将综合扰动 $V_{dist}$ 分解为直流分量与各个频率的交流分量：

- **负载突变** $\rightarrow$ 阶跃信号，非周期，包含从极低频到极高频的连续频谱。
- **输入电压波动** $\rightarrow$ 非周期随机波动，主要包含低、中频的连续频谱。
- **开关纹波** $\rightarrow$ 周期信号，包含基波（开关频率）及其整数倍的高次谐波（离散频谱）。

对每个频率分量独立进行闭环分析。无论是直流还是交流分量，系统实际输出的某一频率分量 $VoS^{(\omega)}$ 均由原始扰动 $V_{dist}^{(\omega)}$ 与控制器产生的补偿信号 $V_{comp}^{(\omega)}$ 共同决定：
$$
VoS^{(\omega)} = V_{dist}^{(\omega)} + V_{comp}^{(\omega)}
$$


可以看出，系统对扰动做出了补偿。$VoS^{(\omega)}$ 是补偿后的信号，它可能被压扁，也可能在特定频段被放大。**因此，$VoS^{(\omega)}$ 真实反映了主电路受到的该频率扰动中，未能被闭环系统（负反馈）完全抵抗掉的残留部分。**

根据线性系统的叠加定理，将所有频率分量（直流与连续交流频谱）的残留部分 $VoS^{(\omega)}$ 在时域上相加（或积分），即可得到最终实际的输出波形总和:
$$
VoS(t) = VoS^{(0)} + \int_{0^+}^{\infty} VoS^{(\omega)}(t) \, d\omega
$$

### 三、 直流分量分析 ($\omega=0$)

如图（d）所示，给定信号 $V_{ref}$ 是一个纯净的直流电压，无高频成分，此时 $V_{ref}^{(0)}=V_{ref}$。

同时，假设外部存在一个恒定的直流扰动 $V_{dist}^{(0)}$。根据闭环控制的基本代数关系：
$$
VoS^{(0)} = V_{ref} \cdot \frac{G(0)}{1+G(0)} + V_{dist}^{(0)} \cdot \frac{1}{1+G(0)}
$$
由于 PID 控制器含有积分环节，其直流开环增益 $G(0) \to \infty$。将其代入上式可得：
$$
VoS^{(0)} = V_{ref} \cdot 1 + V_{dist}^{(0)} \cdot 0 = V_{ref}
$$


**结论：** 在直流稳态下，系统能够完美跟踪给定信号，且 100% 消灭了直流扰动。

### 四、 交流分量分析 ($\omega > 0$)

如图（e）所示，对于任意角频率为 $\omega$ 的交流分量，给定信号无交流成分，即 $V_{ref}^{(\omega)}=0$。

此时，系统完全变成了一个针对交流扰动 $V_{dist}$ 的闭环衰减器。根据负反馈代数关系，补偿信号 $V_{comp}^{(\omega)} = -G(j\omega) \times VoS^{(\omega)}$，代入前面的输出等式有：
$$
VoS^{(\omega)} = V_{dist}^{(\omega)} - G(j\omega) \times VoS^{(\omega)}
$$


移项整理，得到核心的扰动抑制公式：
$$
VoS^{(\omega)} = \frac{V_{dist}^{(\omega)}}{1 + G(j\omega)}
$$

### 五、 终极时域输出公式

如图（f）所示，将无静差的直流分量与被削弱的所有交流分量在时域上进行叠加。设某一角频率为 $\omega$ 的扰动分量在时域表示为 $V_{dist}^{(\omega)}(t) = A^{(\omega)} \sin(\omega t + \phi^{(\omega)})$，则系统最终的输出电压波形为直流与所有交流分量的积分总和：
$$
VoS(t) = V_{ref} + \int_{0}^{\infty} A^{(\omega)} \cdot \left| \frac{1}{1 + G(j\omega)} \right| \cdot \sin\left(\omega t + \phi^{(\omega)} + \angle \frac{1}{1 + G(j\omega)}\right) d\omega
$$


> [^1]:区别傅里叶变换与傅里叶级数：
>
> **周期信号——傅里叶级数**
>
> 对于周期信号（周期为 $T$），基波频率是确定的：$f_0 = 1/T$，$\omega_0 = 2\pi/T$。各次谐波频率就是 $n\omega_0$，是基波的整数倍。频率完全由周期决定，没有任何随意性。
>
> **非周期信号（如阶跃信号）——傅里叶变换**
>
> 阶跃信号不是周期信号，所以不能用傅里叶级数。这时要用**傅里叶变换**，它的思路可以这样理解：
>
> 把非周期信号看作**周期趋于无穷大**的极限情况。当 $T \to \infty$ 时，基波频率 $\omega_0 = 2\pi/T \to 0$，谐波之间的间隔趋于零，离散的频率变成了**连续的频谱**。所以阶跃信号不存在一个"基波频率"，而是**包含从零到无穷的所有频率成分**，每个频率的贡献由频谱密度函数 $X(j\omega)$ 描述。

### 六、 稳定性判据的数学与物理本质

#### 1. 为什么稳定性判据死死盯住增益 **0dB**、相位 **-180°** 的位置？

我们重点分析**开环穿越频率**处的表现。在此频率下，开环传递函数 $G(j\omega)$ 的增益恰好为 **0dB**，即放大倍数为 1。
设此时的相位角为 $\theta$（滞后时 $\theta$ 为负值），那么 $G(j\omega)$ 在复平面上可以用欧拉公式表示为：
$$
G(j\omega) = 1 \angle \theta = \cos\theta + j\sin\theta
$$
将它代入我们之前推导的核心扰动抑制公式，闭环系统对该频率扰动的真实放大倍数为：

$$
\left| \frac{1}{1 + G(j\omega)} \right| = \frac{1}{|1 + \cos\theta + j\sin\theta|} = \frac{1}{\sqrt{(1+\cos\theta)^2 + \sin^2\theta}} = \frac{1}{\sqrt{2 + 2\cos\theta}}
$$
![image-20260317210745453](C:\Users\23227\AppData\Roaming\Typora\typora-user-images\image-20260317210745453.png)

结合上图（幅值随角度 $\theta$ 变化的曲线），我们可以得出极其震撼的结论：

- **物理奇点（θ=−180∘）：** 当滞后达到 **-180°** 时，$\cos(-180^\circ) = -1$，分母 $\sqrt{2 - 2} = 0$。此时 $\frac{V_{dist}}{0} \to \infty$。$VoS^{(\omega)}$ 在瞬间变为无穷大，只要有一丝热噪声，系统就会立刻崩溃发散。
- **临界衰减点（θ=−120∘）：** 当滞后恰好为 **-120°** 时，$\cos(-120^\circ) = -0.5$，分母 $\sqrt{2 - 1} = 1$。此时扰动被 $1:1$ 原样放行（既不衰减也不放大）。
- **放大区（−120∘ 到 −180∘）：** 闭环不仅没有抑制扰动，反而**放大**了扰动幅值。
- **有效衰减区（0∘ 到 −120∘）：** 相位滞后越靠近 **0°**，对应的分母越大，扰动幅值被压制得越小。

#### 2. 物理直观视角（环路相移叠加）

负反馈系统在误差比较器处（取负号）天生自带了 **180°** 的相移。若在某个扰动频率上，控制器和主电路（$G$ 环节）额外产生了 **180°** 的相位滞后，总相移将达到 $180^\circ + 180^\circ = 360^\circ$（即 **0°同相）。该频率下的负反馈瞬间畸变为正反馈**。如果此时增益 $\ge$**0dB**，信号每转一圈都被增强，对外表现为剧烈的自激振荡。

### 七、 交流扰动抑制的残酷真相：会被完全消除吗？

**结论：不会！** 只要该频率 $V_{dist}^{(\omega)}$ 对应的开环增益 $G$ 是一个有限值，分母 $|1+G|$ 就是有限的，输出的残留纹波 $VoS^{(\omega)}$ 就绝对不可能为 0。
针对不同频段的扰动，系统表现如下：

- **极低频段：**$G$ 的幅度极大（例如 **60dB**，即 **1000** 倍）。此时 $|1+G| \approx 1000$。一个 **1V** 的低频波动经过闭环后被压缩为 **1mV**。由于在示波器上难以察觉，宏观上给人一种“完美消除”的错觉，但微观上它依然存在。
- **靠近开环穿越频率：**$G$ 的幅度逼近 1（**0dB**）。此时控制器显得“力不从心”，如前文公式所示，如果相位裕度不足（跌入放大区），$|1+G|$ 的值甚至会小于 1，导致该频率的扰动不仅没被削弱，反而被放大了。
- **远高于开环穿越频率的高频段：**$G$ 极度衰减（例如幅度仅为 **0.01** 倍）。此时 $|1+G| \approx 1$。公式退化为 $VoS^{(\omega)} \approx V_{dist}^{(\omega)}$。这意味着在极高频下，闭环控制器彻底“躺平”，它对高频尖峰和开关噪声起不到任何削弱作用，只能依靠物理层面的输出 LC 低通滤波器来硬抗。

### 八、 开环穿越频率与动态响应的绑定关系

**为什么开环穿越频率决定了响应速度？**
因为开环穿越频率越高，意味着系统在更宽的频带内都拥有大于 **0dB** 的增益 $G$，能够把更多高频分量的扰动狠狠压制住。在系统特性上，**响应速度和带宽是同一物理本质在时域和频域的不同描述**。
开环穿越频率直接划定了控制器能处理的误差边界：

- **低于开环穿越频率的分量**$\rightarrow$ 控制器增益足够 $\rightarrow$ 能有效纠正压制 $\rightarrow$ 对应时域中输出电压的拉回与恢复。
- **高于开环穿越频率的分量**$\rightarrow$ 控制器增益不足 $\rightarrow$ 无法跟踪纠正 $\rightarrow$ 这部分高频误差只能留在输出端。
  负载突变包含极其丰富的高频成分。开环穿越频率越高，控制器能有效吃掉的高频误差分量就越多，负载突变后电压恢复的时间就越短。

### 4. 开关电源稳定性中重要的指标

| 条件         | 作用                           |
| ------------ | ------------------------------ |
| 穿越频率     | 决定系统响应速度               |
| **相位裕度** | **决定系统是否稳定及稳定程度** |
| 穿越斜率     | 保证穿越点附近相位行为良好     |
| 增益裕度     | 辅助稳定性保障                 |

**相位裕度PM：** 在增益穿越频率（幅值=0dB时）对应的相位距离-180°的距离。

**增益裕度GM：** 在相位穿越频率（相位=-180°时）对应的增益距离0dB的距离。

**PM和GM的物理意义：**

- PM = 在穿越频率处，系统距离"反馈方向完全反向"还差多少度相位余量
- GM = 在相位滞后达到-180°时，系统距离"增益足以维持振荡"还有多少增益余量

**两者的关系：**

相位裕度是最基本的稳定性判据，增益裕度是补充判据。 保证穿越频率之前相位不到-180°不是设计选择，而是系统稳定的必要条件。设计时保证PM>45°，本质上就是在保证这个必要条件成立并留有足够余量。

### 6. 负反馈方向正确，为什么还需要稳定性分析

在Buck电路闭环控制仿真中，只要控制器满足"误差为正→占空比增大，误差为负→占空比减小"，系统就能稳定。由此产生疑问：**既然反馈方向始终正确，为什么还需要相位裕度等稳定性判据？**

静态逻辑上，方向确实始终正确：

```
Vo偏高 → e(t)<0 → Duty减小 → Vo下降 ✓
Vo偏低 → e(t)>0 → Duty增大 → Vo上升 ✓
```

这个判断在**静态和低频**下完全成立。但直觉忽略了**时间维度**。

**生活类比：水龙头调温**

> 水管很长，热水需要5秒才到达出水口。水凉了→开大热水（方向正确）→等了几秒没反应→继续开大→5秒后热水涌来烫手→猛关→又变冷→再开大→**持续振荡**

方向始终正确，但**延迟+过大增益**导致系统振荡失控。

**对应Buck电路：**

```
占空比变化
    ↓
电感电流变化（第一次惯性延迟）
    ↓
电容电压变化（第二次惯性延迟）
    ↓
输出电压才发生变化
```

LC双极点最多造成180°相位滞后。当控制器增益过大时，控制器发出减小占空比的指令，但由于LC延迟，这个指令到达输出时时序已经错位，反而起到了推波助澜的效果，负反馈等效变成正反馈，系统振荡。

> **核心：直觉描述的是低频静态行为（方向），稳定性判据描述的是高频动态行为（力度与时序）。方向永远正确，但力度过大会因延迟导致时序错位，使负反馈变正反馈。**

### 6. 穿越频率与截止频率

**穿越频率 (Crossover Frequency, $\omega_c$)**：针对**开环**传递函数，幅值（Gain）等于 $1$（即 $0\text{ dB}$）时的频率。是系统控制力的物理极限（当小于穿越频率可以有效纠正，小于穿越频率的对扰动的纠正程度不高）。

**截止频率 (Cutoff Frequency, $\omega_b$ 或带宽)**：针对**闭环**传递函数，幅值下降到低频增益的 $0.707$ 倍（即下降 $-3\text{ dB}$）时的频率。它主要用来衡量系统的**跟踪能力和响应速度**。


## 5.5 PID补偿

1. PID参数整定方法：

   **1. 经验试凑法**

   最直接的方式，先给 $K_p$ 让系统响应起来，再加 $K_i$ 消除稳态误差，最后加 $K_d$ 抑制振荡。简单但依赖经验，效率低。

   **2. Ziegler-Nichols法（Z-N法）**

   经典的工程整定方法，分两种：一种是基于阶跃响应曲线，从响应中提取延迟时间和时间常数来查表得到PID参数；另一种是临界振荡法，逐渐增大 $K_p$ 直到系统出现等幅振荡，记录此时的临界增益和振荡周期，再按公式算出PID参数。

   **3. 极点配置法**

   在已知被控对象数学模型的前提下，指定闭环极点的期望位置（比如期望的自然频率和阻尼比），反推出PID参数。这是一种时域方法。

   **4. 根轨迹法**

   在s平面上画出闭环极点随增益变化的轨迹，通过选择合适的增益和补偿零极点，使闭环极点落在期望区域内。

   **⭐5. 频域补偿法（给予Bode图）本文使用**

   设定穿越频率和相位裕量目标，在Bode图上**放置零极点来整形环路**，属于频域设计方法。在电力电子中最常用，因为对稳定性指标（相位裕量、增益裕量）控制最直观。

   **6. 数字自整定 / 自适应PID**

   有些数字控制系统会在线自动调整PID参数，比如通过继电反馈法在线辨识对象特性，然后自动计算参数。

   你学的频域补偿法之所以在电力电子中主流，是因为开关电源的被控对象（$G_{vd}$）通常有明确的传递函数模型，而且对带宽、相位裕量、增益裕量这些频域指标有直接的工程要求，用Bode图设计最对口。

2. **频域补偿法流程**

   1. **确定控制对象bode图**
2. **确定设计指标**
   3. **结合Bode根据设计指标设计补偿器**:放置零极点的位置与增益


3. PID本质：

   **解耦：**将PID传递函数转化为时间常数型，PID未知量转化为Ks，wz1与wz2

   > 传统PID形式：
   > $$
   > G_c(s) = K_p + K_i \cdot \frac{1}{s} + K_d \cdot s
   > $$
   > 转化为零极点形式（两个零点、一个原点极点）：
   > $$
   > G_c(s) = \frac{K_s \cdot \left(1 + \frac{s}{\omega_{z1}}\right)\left(1 + \frac{s}{\omega_{z2}}\right)}{s}
   > $$
   >
   > 
   >
   > 两种形式之间的转换关系：
   > $$
   > K_p = K_s\left(\frac{1}{\omega_{z1}} + \frac{1}{\omega_{z2}}\right), \quad K_i = K_s, \quad K_d = \frac{K_s}{\omega_{z1} \cdot \omega_{z2}}
   > $$
   > 
   >
   > Q:为什么先要将PID转化为时间常数型，我直接定pid中3个参数不行吗？
   >
   > A:这是个好问题。理论上你当然可以直接在经典PID形式下固定两个参数、求第三个，但实际操作中零极点形式有明显优势。
   >
   > **经典PID形式的困难**
   >
   > 在经典形式 $G_c(s) = K_p + \frac{K_i}{s} + K_d \cdot s$ 中，三个参数 $K_p$、$K_i$、$K_d$ 对频率响应的影响是耦合的。比如你固定 $K_p$ 和 $K_d$，去求 $K_i$，但 $K_p$ 和 $K_d$ 的**取值直接影响零点位置和相位特性**，你很难直观判断应该把它们固定在什么值上。选得不好，相位裕量可能很差，而你又不知道该怎么调。
   >
   > **零极点形式的优势**
   >
   > 转化为零极点形式后：
   >
   > $$G_c(s) = \frac{K_s \cdot \left(1 + \frac{s}{\omega_{z1}}\right)\left(1 + \frac{s}{\omega_{z2}}\right)}{s}$$
   >
   > 三个参数的物理意义非常清晰且解耦：
   >
   > - $\omega_{z1}$、$\omega_{z2}$ 直接决定零点在频率轴上的位置，你可以在Bode图上直观地看到零点放在哪里会提升多少相位。零点的作用就是在其频率附近提供相位超前，所以你可以根据被控对象 $G_{vd}$ 相位下降严重的频段来"对症下药"地放置零点。
   > - $K_s$ 单独控制整体增益大小，不影响零极点位置，所以可以用穿越频率条件一步求出。
   >
   > **本质区别**
   >
   > 简单来说，零极点形式把"在哪里补偿相位"（由 $\omega_{z1}$、$\omega_{z2}$ 决定）和"补偿多少增益"（由 $K_s$ 决定）分开了。而经典PID形式中，$K_p$、$K_i$、$K_d$ 同时影响增益和相位，调一个参数会牵动其他特性，设计过程就变成了反复试凑。
   >
   > 所以转化为零极点形式不是必须的，而是为了让设计过程更系统、更直观。

2. **关于切载后稳定性的理解：**

   视频中切载后，输出电压发生跌落，随后在占空比自动调节下恢复到给定值。但需要明确：**切载后控制对象的传递函数 $G_{vd}(s)$ 已经改变，恢复稳定不是必然结果，只是在该工况下刚好仍然稳定。**

   **为什么不是必然稳定**

   PID设计基于某个静态工作点的小信号模型，Bode图上的相位裕量和增益裕量只保证该工作点附近的小扰动能收敛。负载大幅变化后，$G_{vd}(s)$ 的直流增益、谐振频率、品质因数都会改变，原有PID参数不一定还能保证足够的稳定裕量。

   **大幅偏离工作点的三种可能**

   - **仍稳定但性能变差**：裕量减小，出现振铃和超调
   - **不稳定**：裕量不足，环路振荡
   - **饱和**：占空比到达限幅，不是稳定性问题，而是超出物理能力

   **工程应对**

   **在多个极端工作点（最大输入+轻载、最小输入+满载等）分别计算 $G_{vd}(s)$，验证同一组PID参数在所有工况下都有足够裕量。**不够则折中调参或采用增益调度。

3. **理想 PID 只能提供相位超前（给甜头），但它没有擦屁股（抑制高频）的能力。** 这就是为什么在需要严苛处理高频噪声的电力电子领域（如开关电源控制），我们更倾向于直接使用 Type 2 或 Type 3 补偿器网络，而不是生搬硬套一个简单的 PID。

## 5.6 系统辨识拟合bode图

1. 使用系统辨识的方法去拟合bode图：在系统输入端注入已知频率的扰动信号，测量输出端的响应，比较输入输出之间的幅值比（增益）和相位差，然后逐点扫频，把这些数据画成Bode图，就得到了系统的频率响应特性。

   **步骤：**

   1. 输入端注入扰动，输出端测量扰动

      > 在控制对象两端加入（控制对象两端），不是闭环传递函数（不然就是闭环传递函数的分析）

   2. 点击模型线性化器，设置注入信号参数。范围包括补偿后的穿越频率点在内就行。注入信号幅值在5-10%就行

      注入信号幅值太大，系统会进入**大信号非线性区域**，此时小信号传递函数 Gvd(s)就不成立了。因为**传递函数本身是在工作点附近做线性化的产物，前提是扰动足够小，系统行为可以近似为线性。**

      幅值过大时具体会出现几个问题：工作点被扰动推离原始位置，器件可能进入饱和或截止等非线性状态（比如电感饱和、占空比打到限幅），系统响应不再和输入成比例关系。这时候你测出来的"频率响应"实际上是**非线性系统在该激励下的某种近似**，不是真正的线性传递函数，辨识结果就不准了。

      所以系统辨识中注入信号的幅值选择是个权衡：**太小被噪声淹没或被滤波器衰减，信噪比差，测不准；太大破坏线性化假设，测出来的不是真正的小信号传递函数，也不准。** 实际工程中一般选择输出扰动在稳态值的1%~5%左右，既能保证信噪比，又不会明显偏离线性区。

1. PID控制→一个零极点+两个零点

2. 控制器设计：
   $$
   G_{c}(s) = \frac{K(s+z_1)(s+z_2)}{s(s+p_1)(s+p_2)}
   $$
   

   - 积分环节：是整个补偿器的"地基"，消除系统的稳态误差，确保系统最终能 100% 追踪到目标值。

     > # **为什么能消除稳态误差的理解：**
     >
     > s是积分环节引入的，想一下只有P，有静态误差，PI没有静态误差。
     >
     > 理论分析：在控制系统中，系统的稳态误差与低频段的开环增益成反比。
     >
     > 假设我们有一个最基础的单位负反馈系统：
     >
     > > **单位负反馈：**H(s)为1
     > >
     > > 在控制系统的框图中，反馈回来的信号通常要经过一个传感器（Sensor）。传感器的传递函数我们通常记为 $H(s)$。
     > >
     > > - **非单位反馈**：如果你的目标是控制电压（$100\text{V}$），但传感器把 $100\text{V}$ 降压转换成了 $5\text{V}$ 的信号传给控制器，那么反馈路径的增益 $H(s) = 0.05$。此时误差方程是 $E(s) = R(s) - 0.05 \cdot Y(s)$。
     > > - **单位反馈**：意思是反馈路径上的传递函数 **$H(s) = 1$**。这意味着传感器完美地、一比一地把实际输出反馈给了比较点。系统直接比较“期望值”和“实际值”，即 $E(s) = R(s) - Y(s)$。
     >
     > - $R(s)$ 是目标输入（参考值）
     > - $Y(s)$ 是实际输出
     > - $E(s)$ 是误差，且 $E(s) = R(s) - Y(s)$
     > - $G(s)$ 是开环传递函数（控制器 + 被控对象）
     >
     > 根据闭环系统的逻辑，输出等于误差乘以开环传递函数：
     >
     > $$Y(s) = E(s)G(s)$$
     >
     > 把这个式子代入误差方程 $E(s) = R(s) - Y(s)$ 中，我们可以得到**误差传递函数**：
     >
     > $$E(s) = \frac{R(s)}{1 + G(s)}$$
     >
     > **现在，重点来了！** 我们关心的是“稳态误差”（$e_{ss}$），也就是时间 $t \to \infty$ 时的误差。在复频域（$s$ 域）中，根据拉普拉斯变换的**终值定理**，时间趋于无穷大等价于 $s$ 趋于 $0$：
     >
     > $$e_{ss} = \lim_{t \to \infty} e(t) = \lim_{s \to 0} s E(s)$$
     >
     > 假设我们给系统一个最常见的阶跃指令（比如突然设定一个恒定值），阶跃信号在 $s$ 域的表达是 $R(s) = \frac{A}{s}$（$A$ 为阶跃幅值）。代入上面的终值定理公式：
     >
     > $$e_{ss} = \lim_{s \to 0} \left[ s \cdot \frac{A/s}{1 + G(s)} \right] = \lim_{s \to 0} \frac{A}{1 + G(s)} = \frac{A}{1 + \lim_{s \to 0} G(s)}$$
     >
     > **结论呼之欲出：**
     >
     > 公式分母里的 $\lim_{s \to 0} G(s)$，在物理意义上就是**频率 $\omega \to 0$ 时的开环增益**，也就是 Bode 图最左侧的**直流增益（低频段增益）**。
     >
     > 显然，**低频开环增益 $\lim_{s \to 0} G(s)$ 越大，稳态误差 $e_{ss}$ 就越小。** 两者呈严格的反比关系。

   - 比例环节：幅值增益一条直线，相位为0，目的是移动穿越频率，使得右移

   - 零点（一阶微分）：放在目标穿越频率左边（ $f_c$ 的 1/10 到 1/3 处）这样到穿越频率时，零点的相位超前效果已经充分发挥（接近但不一定恰好90°，取决于零点与 $f_c$ 的距离），但是在穿越频率处的幅值增益不大，对穿越频率的影响很小。副作用分析：零点在提供相位超前的同时，也给高频带来+20dB/dec的增益上翘。

   - 极点（惯性环节）：与零点配套出现将极点放在 $f_c$ 右侧足够远的位置。极点的增益下拉作用主要在高频段起效，强行将零点引起的增益上翘压下来；而极点带来的相位滞后因为距离穿越频率远，在 $f_c$ 处的影响很小，不会显著破坏相位裕度。

     > ## 零极点配置的核心原则
     >
     > 设计总原则：零点频率 < 穿越频率 f_c < 极点频率。
     >
     > ### 零点放在穿越频率左侧
     >
     > 核心目的：提升相位裕度（Phase Margin）。
     >
     > 原理：零点（一阶微分环节）提供正的相位超前。一个零点在其频率 f_z = 1/T 处提供+45°相位超前，在更高频段趋于+90°。
     >
     > 放置策略：将零点放在 f_c 的 1/10 到 1/3 处。这样到穿越频率时，零点的相位超前效果已经充分发挥（接近但不一定恰好90°，取决于零点与 f_c 的距离），能有效抵消被控对象的相位滞后。两个零点通常不放在同一频率，而是分散配置，拓宽相位补偿带宽。
     >
     > 副作用分析：零点在提供相位超前的同时，也带来+20dB/dec的增益上翘。但由于零点在 f_c 左侧，且积分极点本身提供-20dB/dec的衰减，两者部分抵消，因此零点对穿越频率右移的影响是可控的。总体而言，在 f_c 附近，零点"往上捞相位"的正面作用远大于增益上翘的负面影响。
     >
     > ### 极点放在穿越频率右侧
     >
     > 核心目的：提升幅值裕度（Gain Margin）并抑制高频噪声。
     >
     > 原理：极点（惯性环节）从其频率 f_p 开始引入-20dB/dec的增益衰减和相位滞后。
     >
     > 放置策略：将极点放在 f_c 右侧足够远的位置。极点的增益下拉作用主要在高频段起效，强行将零点引起的增益上翘压下来；而极点带来的相位滞后因为距离穿越频率远，在 f_c 处的影响很小，不会显著破坏相位裕度。
     >
     > 副作用分析：极点在高频段提供增益衰减的同时也引入相位滞后，但因为 f_p 远大于 f_c，这部分相位滞后在穿越频率处尚未充分体现，对系统稳定性的负面影响很小。

     **关键：**

     **①零极点的作用分析盯紧穿越频率处**

     **②积分是零静态误差基础，比例移动穿越频率，零点是增加相位裕度，极点配套零点消除零点高频幅值增益上翘，同时抑制高频开关噪声。**
     
     **③比例环节是最后加的，前面添加零极点都是假设比例已经使得穿越频率达到目标了，因为零极点会影响比例取值。比例仅仅会移动幅频特性，对相频特性没影响，这就是定参数都是定参方法是确定零极点，再定比例环节**

## 5.9 电流模式

1. 现有控制方式的一些总结：

   1. **电压模式 (Voltage Mode Control)：输出电压单环控制**

      **工作原理**：**单环系统**。系统仅采集输出电压，将其与参考电压进行比较，误差信号经过补偿网络处理后，决定下一个开关周期的占空比。

      **优缺点**：这种模式的优点是结构简单、易于设计和分析。

      **主要缺点是响应存在延迟：**当buck输入电压或负载发生突变时，必须等到输出电压切实发生改变后，误差放大器才会动作去调节占空比，因此瞬态响应较慢。

   2. **电流模式 (Current Mode Control)：输出电压外环 + 电流内环**

      **工作原理**：这是一种**双环嵌套系统**。外环同样是采集输出电压，但它的误差放大器输出作为**内环电流的参考指令（给定值）**。电流内环则直接监视和控制电感电流或开关管电流，使其跟踪外环给定的指令。

      根据内环控制电流特征的不同，准确地分为您提到的两种方式：

      1. **峰值电流控制 (Peak Current Mode)**：内环通过直接限制电感或开关器件的峰值电流来工作。这种方式动态响应极快，并且具有内在的“逐周期过流保护”功能,。但其缺点是，当占空比大于50%时系统容易出现次谐波振荡，必须加入**斜坡补偿**才能稳定,。
      2. **平均电流控制 (Average Current Mode)**：内环通过引入补偿器来控制电感的平均电流，使其保持为恒定值或跟随参考波形,。由于输出电压与平均电流直接成正比，这种技术非常优秀，它抗噪声干扰能力强，且在任何占空比下都能稳定工作，无需额外加斜坡补偿,。它还广泛应用于PFC（功率因数校正）和电池充电器等需要精确控制电流平均值的场合,。

2. ![image-20260318101441970](C:\Users\23227\AppData\Roaming\Typora\typora-user-images\image-20260318101441970.png)

   **为什么需要电流模式的双环结构：**

   1. 提高响应速度，先于单纯电压环：当输入电压波动时，到影响输出电压会经过LC的延迟，但是由于L两端的电压变化，电感电流瞬间变化，立马就会被电流内环捕捉到。对于负载变化时，由于会产生电压跌落，电压环电流环都能快速捕捉到。这种对输入电流的直接检测赋予了系统内在的前馈控制特性，从而实现了更快的反应时间。
   2. 降低了系统的传递函数阶数，使得外环可以设计出更高的带宽 从控制理论与波特图的角度来看，由于电流内环的存在，功率级的动态特性被大大简化。它将原本电压模式下由LC滤波器造成的含有双极点的二阶系统，在感兴趣的频段内降阶为一个单极点的一阶系统。 这种降阶效应使得系统在低频部分不易发生剧烈的相位跌落，更容易满足相位裕量的要求，简化了外环的补偿设计。因为系统固有的稳定性得到了提升，设计人员就可以将外部电压环的控制带宽（穿越频率）设计得更宽，进而带来更加优异的阶跃负载响应和瞬态响应速度。

# MathCAD

1. ![image-20260315102650868](C:\Users\23227\AppData\Roaming\Typora\typora-user-images\image-20260315102650868.png)

   在这张图上，曲线在谐振点之后**确实显示的是正数**（比如在 $1\text{kHz}$ 附近大约是 $+150^\circ$，在 $10\text{kHz}$ 附近大约是 $+100^\circ$）。

   但是，这其实是绘图软件（看公式的字体和排版，应该是 Mathcad 或类似的数学软件）给你放的一个**“视觉烟雾弹”**！

   在控制理论和数学绘图中，这叫作**相位折叠（Phase Wrapping）**。我们来拆解一下这个现象背后的物理真相：

   ## 1. 软件的“数学死板”

   请看你图中的纵坐标公式：$\arg(G_{vd}) \cdot \frac{180}{\pi}$。

   在数学软件里，复数的辐角函数 `arg()` 默认会把计算出的所有角度严格限制在 **$-180^\circ$ 到 $+180^\circ$**（即 $-\pi$ 到 $\pi$）之间。

   ## 2. 还原真实的物理相位（Unwrapped Phase）

   我们顺着物理逻辑，从左往右重新走一遍你的相位图：

   - **突变的那根竖线：** 当真实的物理相位掉到 $-180^\circ$，并且准备继续往下掉（比如变成 $-181^\circ$）时，软件的 `arg()` 函数处理不了小于 $-180^\circ$ 的数。在数学上，$-181^\circ$ 和 $+179^\circ$ 是同一个位置，所以软件**瞬间把画笔从底部拉到了顶部**。（也就是自动加了360°）
   - 因此：**真实物理相位 = 图面显示相位 - $360^\circ$**
